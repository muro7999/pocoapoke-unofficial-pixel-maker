# ぽこあポケモン 推しドット絵メーカー（非公式）

画像をドット絵に変換し、必要なゲーム内素材を確認できる非公式のファンメイドツールです。ブラウザだけで利用できます。

## オンライン版

<https://muro7999.github.io/pocoapoke-unofficial-pixel-maker/>

## データの取り扱い

画像および作品データの処理は、利用者のブラウザ内で行われます。作品はブラウザのIndexedDBに保存されますが、ブラウザデータの削除や端末・ブラウザの変更により失われる場合があります。必要な作品はJSONなどで書き出して保管してください。
