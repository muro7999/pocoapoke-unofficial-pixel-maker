# ぽこあポケモン 推しドット絵メーカー（非公式）

画像をドット絵に変換し、必要なゲーム内素材を確認できる非公式のファンメイドツールです。ブラウザだけで利用できます。

## オンライン版

<https://muro7999.github.io/pocoapoke-unofficial-pixel-maker/>

## プライバシー・データの取り扱い

このツールはブラウザ上で動作する静的な単一HTMLです。専用のアプリサーバー、ユーザーアカウント機能、アクセス解析機能は使用していません。

- 利用者が選択した画像、変換後のドット絵、作品データは、アプリのサーバーへ送信・保存されません。
- 画像変換、素材計算、JSON・PNG・QRの生成と読み取りは、利用者のブラウザ内で処理されます。
- 「マイ作品」のデータは、利用中のブラウザのIndexedDBにのみ保存されます。
- カメラ映像はQRコードの読み取りにのみ使用し、本ツールから録画・アップロード・保存する処理はありません。
- JSON・PNG・QRなどは、利用者が書き出しや共有を実行した場合にのみ端末へ保存されます。

GitHub Pagesでのページ配信に伴い、IPアドレスなどの一般的なアクセス情報をGitHub側が取り扱うことがあります。これは本ツールが画像や作品データを収集するものではありません。

ブラウザデータの削除や端末・ブラウザの変更により、IndexedDB内の作品が失われる場合があります。必要な作品はJSONなどで書き出して保管してください。
